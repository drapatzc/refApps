These demo apps were specifically created for the toolbox and xcodex tools to test different Xcode project configurations (e.g. SPM, CocoaPods, Carthage, as well as unit and UI tests).
They are not intended for production use, but are solely used to thoroughly validate the tools under realistic conditions.

**xcodex** is the lightweight version — focused on what you actually need in daily development:
🧰 https://xcodex.betterlocale.com

**toolbox** is the full-featured version with around 400 functions and a fully customizable menu:
🧰 https://toolbox.betterlocale.com
